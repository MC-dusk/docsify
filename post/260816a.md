# Windows"更好的性能"与写入缓存深度解析：FUA 命令如何"阉割"你的硬盘

> 在 Windows 设备管理器中，每个硬盘驱动器的「属性 → 策略」选项卡下都有"更好的性能"和"启用设备上的写入缓存"两个选项。大多数人只知道"开了更快"，却不清楚背后的真实机制。本文从一次 USB 硬盘盒的实测出发，逐层揭开写入缓存的运作原理，最终揭示一个被广泛误解的真相——**写入缓存的本质不是"用内存暂存数据"，而是一个硬盘命令执行模式的开关**。

------

## 一、基本概念

### 1.1 写入缓存（Write Caching）

写入缓存是一种利用高速内存（RAM）作为硬盘写入缓冲区的技术。当系统需要向硬盘写入数据时，不会直接将数据写入速度较慢的硬盘，而是先将数据临时存储在速度极快的系统内存中，然后在系统空闲时，由后台进程将缓存中的数据批量写入硬盘。

### 1.2 "更好的性能"选项

这是 Windows 提供的两种**删除策略**之一（另一种是"快速删除"）。选择"更好的性能"后，系统会自动启用硬盘的写入缓存功能，并允许使用高级写入命令，以最大化硬盘的读写性能。

| 特性         | 更好的性能                  | 快速删除                   |
| ------------ | --------------------------- | -------------------------- |
| 写入缓存     | 启用                        | 禁用                       |
| 写入性能     | 高                          | 低                         |
| 数据安全性   | 较低（需安全删除）          | 高（可随时拔出）           |
| 适用场景     | 内置硬盘、有 UPS 保护的系统 | U 盘、移动硬盘等可移动设备 |
| 系统资源占用 | 较高                        | 较低                       |

------

## 二、三层缓存架构

在 USB 硬盘盒场景下，数据写入实际上会经过**三层缓存**的接力处理：

```
应用程序 → Windows 系统文件缓存 → USB 桥接芯片缓存 → 硬盘内置 DRAM 缓存 → 物理盘片
```

理解这三层架构，是理解后续性能差异的基础。

------

## 三、核心机制：FUA 命令才是真正的"性能杀手"

> 这是本文最核心的部分。绝大多数关于写入缓存的解释都停留在"缓存数据"的层面，而忽略了真正决定性能的关键因素——**硬盘命令的执行模式**。

### 3.1 "快速删除"模式的真实行为

"快速删除"不仅仅禁用了系统级写回缓存，更关键的是，它会**强制硬盘也禁用写回缓存**。具体做法是：

- 系统对每个写入命令自动添加 **FUA（Force Unit Access，强制单元访问）** 标志
- FUA 命令要求硬盘：**必须将数据真正写入物理盘片后，才能向系统返回"写入完成"信号**
- 硬盘的内置 DRAM 缓存此时只能用作读缓存和写命令的临时排队，**不能用作写回缓存**
- 命令队列深度被强制限制为 **1**，即严格串行执行：发送一个命令 → 等待完成确认 → 再发送下一个

### 3.2 "更好的性能"模式的真实行为

这是一个**双重解锁**的过程，同时释放了系统和硬盘两端的缓存能力：

- **系统端**：启用写回缓存，数据先写入系统内存，立即向应用程序返回"写入完成"，后台批量写入硬盘
- **硬盘端**：不再发送 FUA 命令，允许硬盘使用内置 DRAM 缓存进行写回操作
- **启用 NCQ（原生命令队列）**：允许硬盘同时接收最多 32 个写入命令，并自主决定执行顺序，将零散的写入请求合并为连续的大块写入

### 3.3 为什么 FUA 模式会严重拖慢硬盘？

机械硬盘的每次写入都包含三个不可避免的机械延迟：

| 延迟类型     | 说明               | 典型值（5400RPM） |
| ------------ | ------------------ | ----------------- |
| 寻道时间     | 磁头移动到目标磁道 | ~12ms             |
| 旋转延迟     | 盘片旋转到目标扇区 | ~5.5ms            |
| 数据传输时间 | 实际写入数据       | 取决于数据量      |

在 FUA 单命令同步模式下，**每一个写入块都要完整经历这三个延迟**，即使磁头已经在正确位置也不例外，因为必须等上一个命令完全确认后才能开始下一个。

简单估算（假设每个写入块 64KB）：

```
每块总延迟 ≈ 12ms + 5.5ms + 0.3ms ≈ 17.8ms
每秒写入块数 ≈ 1000 / 17.8 ≈ 56 块
理论速度 ≈ 56 × 64KB ≈ 3.5MB/s
```

实际中由于固件层面的基本优化，速度会高于这个理论值，但串行执行的根本限制决定了性能上限极低。

### 3.4 解除 FUA 后为什么能达到全速？

启用 NCQ 和批量写入后，工作模式变为：

1. 系统一次性向硬盘发送 32 个连续的写入命令
2. 硬盘固件识别出这些命令指向连续的逻辑地址
3. 将 32 个命令**合并成一个单一的物理写入操作**
4. 磁头只需移动一次，然后连续写入所有数据

当合并的数据量足够大时，寻道和旋转延迟的开销几乎可以忽略不计，写入速度就等于物理盘片的线速度。

## 四、实测验证：两块硬盘的天壤之别

以下测试基于 USB 硬盘盒 + CrystalDiskMark，测试数据量均超过 1GB，远超两块硬盘的缓存容量，因此结果反映的是**真实物理盘片写入速度**。

### 4.1 西数紫盘 WD43PURZ（监控盘）

| 参数                 | 值                   |
| -------------------- | -------------------- |
| 转速                 | 5400RPM              |
| 内置缓存             | 256MB DRAM           |
| 单碟容量             | 2TB（2 碟 4TB，CMR） |
| 官方标称持续传输速度 | 175MB/s              |

| 模式                   | 实测顺序写入  |
| ---------------------- | ------------- |
| 快速删除（FUA 开启）   | **~60 MB/s**  |
| 更好的性能（FUA 关闭） | **~200 MB/s** |
| **性能提升**           | **~233%**     |

**分析**：紫盘虽然只有 5400RPM，但得益于超大的单碟容量（2TB/碟），其面密度和线速度已经超过很多老款 7200RPM 硬盘，外圈真实速度可达 200MB/s 以上。60MB/s 是被 FUA 单命令模式严重限制后的虚假速度，200MB/s 才是它真实的物理盘片速度。

### 4.2 西数黑盘 WD5000LPLX（高性能笔记本盘）

| 参数     | 值        |
| -------- | --------- |
| 转速     | 7200RPM   |
| 内置缓存 | 32MB DRAM |
| 尺寸     | 2.5 英寸  |

| 模式                   | 实测顺序写入  |
| ---------------------- | ------------- |
| 快速删除（FUA 开启）   | **~140 MB/s** |
| 更好的性能（FUA 关闭） | **~145 MB/s** |
| **性能提升**           | **~3%**       |

**分析**：黑盘的高转速（7200RPM）和低延迟固件设计，让它在 FUA 模式下的性能损失很小。旋转延迟约 4.2ms，寻道时间约 9ms，比紫盘快 30% 以上。它的真实物理速度约为 145MB/s，在 FUA 限制下仍能接近这个数值。此外，测试数据为 16MB 时结果略好（数据可完全放入 32MB 缓存），大于 128MB 后稳定在 145MB/s 左右。

### 4.3 对比总结

| 特性                  | 紫盘 WD43PURZ | 黑盘 WD5000LPLX |
| --------------------- | ------------- | --------------- |
| 真实物理盘片速度      | 外圈 ~200MB/s | 全程 ~145MB/s   |
| FUA 模式速度          | 60MB/s        | 140MB/s         |
| 关闭 FUA 后速度       | 200MB/s       | 145MB/s         |
| 性能提升幅度          | ~233%         | ~3%             |
| 对 FUA 命令的敏感度   | 极高          | 极低            |
| 对 NCQ/批量写入的依赖 | 极强          | 极弱            |

## 五、写入缓存的终极真相

综合以上分析，可以给出一个更准确的定义：

> **Windows 设备管理器中的"启用设备上的写入缓存"，本质上是一个"硬盘命令执行模式开关"。它的主要作用不是"利用内存临时存储数据"，而是"允许硬盘使用 NCQ 和批量写入技术来优化命令执行顺序"。**

- 缓存大小只是次要因素。即使硬盘只有很小的缓存，只要它能合并连续的写入命令，开启写入缓存后仍会获得巨大提升。
- "快速删除"模式为了实现"随时可以安全拔出"的承诺，不惜牺牲了硬盘 90% 以上的潜在性能，将其强制降级到单命令同步执行的原始模式。

------

## 六、不同硬盘类型的规律

根据以上机制，可以总结出一般性规律：

| 硬盘类型                               | 典型特征                         | 开启写入缓存后的提升                     |
| -------------------------------------- | -------------------------------- | ---------------------------------------- |
| 大缓存 + 低转速（监控盘、归档盘）      | 高面密度、大缓存、固件偏批量优化 | **提升巨大**（可达 200%+）               |
| 小缓存 + 高转速（高性能桌面/笔记本盘） | 低延迟、固件偏快速响应           | **提升很小**（~5% 以内）                 |
| SSD                                    | 无机械延迟                       | **提升有限**，但可减少写入放大、延长寿命 |

------

## 七、使用建议

| 场景                             | 建议                             |
| -------------------------------- | -------------------------------- |
| **内置硬盘（台式机）**           | 强烈建议开启。担心断电可搭配 UPS |
| **笔记本电脑**                   | 放心开启，电池本身就是天然 UPS   |
| **USB 移动硬盘（大缓存监控盘）** | 强烈建议开启，可获得数倍提升     |
| **USB 移动硬盘（高性能盘）**     | 开不开差别不大，按需选择         |
| **U 盘 / 移动存储**              | 建议保持默认"快速删除"           |
| **服务器 / 重要数据**            | 必须使用 UPS + 定期备份          |

### USB 硬盘盒的额外注意事项

- **桥接芯片**：主流芯片（JMS578、ASM1153E 等）正确支持 FUA 和写入缓存控制，但廉价芯片可能忽略 FUA 命令，存在数据丢失风险。
- **安全删除**：对开启了"更好的性能"的 USB 硬盘，安全删除操作会触发两次刷新——先刷新 Windows 系统缓存，再向硬盘发送 FLUSH 命令强制写入盘片。两步完成后才能安全拔出。

------

## 八、常见误区

| 误区                         | 事实                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| 开启写入缓存会影响读取性能   | 写入缓存只影响写入操作，对读取无负面影响                     |
| SSD 不需要开启写入缓存       | SSD 同样受益，尤其是小文件写入和延长寿命                     |
| 正常关机也会丢数据           | 正常关机时系统会自动刷新缓存，不会丢失数据。只有突然断电或系统崩溃才有风险 |
| 写入缓存就是"用内存暂存数据" | 缓存只是次要因素，核心是解除 FUA 限制、启用 NCQ 批量写入     |
| 数据量超过缓存就没效果       | 性能提升来自 NCQ 和命令合并，与缓存容量无直接关系            |

------

## 九、结语

Windows 的"更好的性能"选项远不止"开个缓存"这么简单。它的本质是**解除 FUA 命令对硬盘的串行化限制，释放 NCQ 和批量写入能力**。对于大缓存、低转速、高面密度的硬盘（如监控盘、归档盘），这一开关可以带来数倍的性能提升；而对于低延迟设计的高性能硬盘，提升则微乎其微。理解了这个机制，你就能根据自己的硬盘类型做出最合理的选择。
